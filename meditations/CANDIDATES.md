# Candidates — the promotion ledger

> **This is a template.** The real ledger fills with candidate blocks over
> weeks of nightly runs.
>
> Every idea that might climb the ladder lives here from first sighting until
> it is promoted or dropped. Gates and tier definitions: `MEDITATIONS.md`.
> An idea that is not in this ledger cannot be promoted. This file is what
> turns "this keeps coming up" into a count.

Format per candidate. Append new sightings to the same block — never open a
second block for the same claim.

```
### <kebab-slug>
- **Claim:** one sentence, falsifiable.
- **Tier:** 0 | 1 | 2 | 3
- **Status:** watching | promoted | dropped
- **Sightings:** YYYY-MM-DD <reflection-file>; YYYY-MM-DD <reflection-file>
- **Next gate:** what is still missing to climb.
```
