# Workbench — the making half of the practice

> **This is a template.** The real log fills with one entry per meditation run.
>
> Reflection notices. The workbench builds. One piece of real work per
> meditation run, the agent's to choose: code, an essay, a song, a tool, a
> design.

**The one hard rule:** artifacts live in `meditations/workbench/` and nowhere
else. Never a write into any other repo, even when the work is *for* one. The
meditation runs unattended with elevated permissions and other agents share
those repos. Work that targets a real project lands here as a proposal with a
pointer to where it would go, and the human moves it.

**Prefer continuing over starting.** Read this file before choosing. If a piece
is `in progress`, advance it. Start something new only when nothing is open or
the open piece is genuinely finished. Novelty every night just builds a
graveyard.

States: `in progress` · `finished` · `parked`. Parked is honest. Abandoned
without saying so is not.
